# P0 基礎與接手

目標：安全接續既有 Rust 服務與資料庫基礎，不覆蓋其他工作。

依據：[主計畫](../../PLAN.md)、[既有基礎工作](../bootstrap.loop.md)。目前工作樹有未提交修改；既有記錄的結果須以實際證據核對。

步驟：確認唯一工作者、分支、工作樹與既有程序；查基礎驗證原件與目前版本是否一致；必要時執行專案檢查與隔離資料庫容器驗收，保存輸出。確認後再進 P1；ORCA 前景問題若不阻擋產品開發，另記未完成，不讓它佔住主線。

驗收：知道工作樹歸屬與變更範圍；服務啟停、版本、資料庫正常與中斷／恢復有對應版本的實測。未驗項寫明，不改寫其他人的資料。下一步及證據回填母檔。
