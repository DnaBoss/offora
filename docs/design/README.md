## 設計方向

暖木地板、奶油色牆面、鼠尾草綠與陶土色的俯視像素辦公室，搭配深藍灰導覽及清晰中文。場景與角色使用像素語言；文字面板使用正常字型，避免職稱與訊息難讀。

主畫面分為空間／成員導覽、辦公室、選中交談紀錄。人類先看誰在工作與交談，再點角色或群組查原始訊息。左側工作名稱只是外部工作參照，不是任務看板。沒有派工、批准、執行、完成率等控制。

示例六個 session：後端 B01、B02；前端 F01、F02；美術 A01、A02。B01 與 F01 已聚集，F02 正前往，A01／A02 在另一區討論，B02 在桌前工作。每人只出現一次，頭頂職稱與代號常駐。虛線路徑表示即將交談，不代表訊息必須等人走到才送。

右側僅讀交談紀錄，顯示發話者、時間、原文與參與者；底部提示「狀態由 AI 回報」。顏色之外仍用文字區分工作、交談與移動。正式製作前另驗窄螢幕、鍵盤操作、減少動態、離線及載入失敗畫面。
